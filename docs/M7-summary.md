# M7 · 模板与导出

2026-10-10，M7-1 至 M7-5 已完成。入口为导航栏的 `/export`，生成结果也提供选模板导出链接。无需新增数据库迁移。

## 交付行为

- 经典单栏与现代双栏两套模板。现代版将章节标题置于侧栏，正文按原分区顺序阅读；使用普通块流保证 Chromium 长文分页。
- 多岗位共用素材生成：最多 20 个 JD、60 条素材，岗位并发上限 2，单个岗位失败不影响其他结果。
- 按关键词、岗位、是否包含要点筛选已有简历；选择模板后使用 PDF.js 展示实际 PDF 分页，单份下载复用同一个 Blob。
- 最多 20 份简历打包 ZIP。空要点不能勾选，文件名清理路径及非法字符并附完整 UUID，同名简历不会覆盖。
- 刷新后可恢复上次批次；取消等待后可重试同一批。部分失败可跳转生成页恢复指定任务、重试失败经历。

## 数据与恢复设计

模板注册表提供 ID、名称、描述和布局；frozen `ResumeDocument` 只暴露标题、姓名、分区和文本等展示字段，模板不依赖数据库 ID、证据或生成状态。模板切换通过预览/导出 query 参数完成，不改内容及 revision。

浏览器保存 `batch_id` 与选择项；每个岗位的 `run_id` 使用 UUID5(batch_id, jd_id)，沿用 M4 的 Postgres checkpoint。相同请求复用已完成结果，不重新 upsert；同一 run ID 更换素材返回冲突。新内容需开始新批次。

批次结果保留生成快照，导出列表在生成或重试完成后重新读取数据库中的当前简历，因此后续人工编辑不会被旧快照覆盖。列表刷新失败时保留批次结果，提供独立刷新按钮。生成已提交后，取消浏览器等待不保证服务器停止执行。

ZIP 先检查所有简历的所有权及要点，再渲染全部 PDF。任何渲染失败都会返回错误，不提供残缺压缩包，也不会标记已导出。全部渲染成功后更新导出标记；此标记不属于简历编辑版本。

## 接口

| 接口 | 行为 |
|---|---|
| `GET /api/v1/resumes/templates` | 可用模板元数据 |
| `GET /api/v1/resumes` | 当前用户简历，按更新时间排序 |
| `POST /api/v1/resumes/batch-generate` | `{batch_id, jd_ids, experience_ids}`，按输入顺序返回各岗位结果 |
| `POST /api/v1/resumes/export` | `{resume_ids, template}`，返回 ZIP |
| `GET /api/v1/resumes/{id}/pdf?template=modern` | 指定模板的当前简历 PDF |
| `POST /api/v1/resumes/{id}/preview?template=modern` | 指定模板的未保存编辑草稿 PDF |

已有 HTML 预览接口也支持模板选择。未知模板返回 400，重复 ID 或超数量请求返回 422；批量生成的岗位失败在对应结果项中返回。
